# mini-erp-confeccao

## Problema

Uma confecção planeja produzir uma quantidade exata de peças, mas a produção
pode gerar perdas de matéria-prima durante o corte e peças com defeito, que
podem ser classificadas como produtos de segunda. Por isso, a quantidade
planejada nem sempre corresponde à quantidade de peças boas disponíveis para
venda.

Quando essas perdas não são registradas, o sistema pode indicar um estoque
maior do que o real, levando o e-commerce a vender peças que não existem.
Além disso, um consumo de material diferente do previsto pode causar falta de
insumos e impedir a conclusão da ordem de produção.

Este projeto busca representar essas ocorrências de forma confiável: registrar
as perdas como movimentações de estoque, separar as peças de segunda, recalcular
a necessidade de matéria-prima com base na ficha técnica e apresentar o saldo
realmente disponível para venda e produção.
